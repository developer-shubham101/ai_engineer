# Product Specification: VajraScope v3.0
**Developed by:** Vajra Solutions
**Category:** Enterprise Business Intelligence Tool

## Description
VajraScope is a predictive analytics dashboard designed for non-technical C-suite executives. Unlike Tableau or PowerBI which require data analysts to build views, VajraScope uses Natural Language Processing (NLP) to generate charts.

## Key Features
*   **"Ask Agni" Interface:** Users can type questions like "Show me Q3 sales predictions for Tokyo vs. Mumbai" and get an instant graph.
*   **Data Sources:** Integrates seamlessly with SAP, Salesforce, and Oracle DB.
*   **Anomaly Detection:** Automatically alerts users via SMS/Email if KPIs drop below a set threshold (e.g., >10% dip in daily active users).

## Pricing Tiers
*   **Starter:** $500/month (Up to 5 users, Weekly Data Refresh).
*   **Professional:** $2,500/month (Up to 50 users, Daily Data Refresh).
*   **Enterprise:** Custom Pricing (Unlimited users, Real-time Data, Dedicated Support Engineer).

## Technical Requirements
*   **Browser:** Chrome 90+, Edge 88+, Firefox 85+.
*   **Deployment:** Available as SaaS (Hosted on AWS) or On-Premise (Docker Container).
